# Bug-hunt fixes: the map's core (`map_core`)

Branch `fix/bughunt-map_core` (worktree `its worktree `), not merged or pushed.

- CMSG_ZONEUPDATE is trusted: **fixed**, 1ec9e945. The zone comes from `world::update_zone` wherever `zone_and_area` has an answer. The client's value is used only where there's no navmesh, terrain or indoors box. A mismatch is logged at `debug`. Test: `tests_map_core::a_client_does_not_pick_its_own_zone_where_the_server_knows_it`.
- A knockback gives a 10-second window: **partly fixed**, 36315f8e. During a launch, FLYING, CAN_FLY and LEVITATING are now taken off. Test: `tests_p12c_flags::a_knockbacks_flight_gives_no_flying`. The rest is **deferred**: the ballistic end time and refilling only `xy_speed * elapsed`. mangos-classic itself keeps `IsLaunched` until the landing packet, with no timer and no flag check ("maybe false positives"). A knockback off a cliff legitimately keeps its launch speed for longer than `2*vz/g`, so a ballistic cap would pull real falls back. That is a stricter-than-mangos rule, so it's the user's call.
- A client that never sends MSG_MOVE_WORLDPORT_ACK acts unseen: **fixed**, 1d59be22. While `awaiting_worldport`, only the ack, queries, account data, trade cancel, action bar toggles and logout are handled, after the movement acks. This follows mangos's STATUS_LOGGEDIN rule; chat is dropped too, as in mangos. Test: `tests_map_core::a_client_still_loading_a_map_acts_on_nothing_there`. The 60-second kick is **deferred**: mangos has none, and a client that withholds the ack can now do nothing anyway.
- The player public mask leaves out emote and aura state: **fixed**, db12d5eb. `UNIT_FIELD_AURASTATE` and `UNIT_CREATED_BY_SPELL..=UNIT_NPC_EMOTESTATE` were added, and only the player's mask was changed. The client check (`tests_client_emu`, `tests_p8_movement_client`) passes. Test: `tests_map_core::another_player_sees_a_players_emote_and_aura_states`.
- The possessed unit's movement checks: **skipped**. It is fixed under combat_ai.
- A creature despawned while marked for visibility is introduced again: **fixed**, 210ce558. `despawn_from_view` now removes the creature from `visibility_dirty`. Test: `tests_map_core::a_creature_despawned_while_marked_is_not_introduced_again`. The second suggestion was **not done**: making `prepare` refuse any object with no grid entry is broader than the bug, since new arrivals are taken whole.
- Forgets are quadratic: **fixed**, c13308c9. The forgets are counted once in a hash map, and the new `Batch::settle_forgets` does the creates count, the forget and the drop in one indexed pass. Test: `update::tests::forgets_settle_at_once_as_they_did_one_by_one`, which checks the behaviour. No timing test was added.
- Tiles ahead miss corner tiles and use the continents' reach: **fixed**, 6d514e39. `tiles_around` now lists every tile whose square the disc touches. `ahead` and `keep_near_players` use `visibility::sight + 20`. Test: `tiles::tests::the_tiles_around_are_every_one_the_disc_touches`.
- Dead and looser duplicate arms in handlers.rs: **fixed**, 6299d022. The arms were removed. There's no test: the code was unreachable.
- Traps walk every game object: **fixed** for the trap look, 8f0d8b0a. `Objects::trap_objects` is kept up to date in `add_gameobject` and `remove_gameobject`, and the existing trap tests pass. The rest is **deferred**: limiting the look to traps in a player's view would change which traps creatures can spring, and indexing spawns by GUID in `GameData` only matters per event, not per tick.
- A creature's speed change scans every player: **fixed**, b539519f. It now uses `movement::controller`. Two tests that set `owned.mover` by hand now also set the unit's `CHARMEDBY`, as play does.
- The values flush walks every item: **deferred**. Each item already costs only two flag reads (`values_block` and `clear_dirty` both return on `any_dirty`). A per-player dirty flag would need every item-field write behind a setter, which is a wide change for little gain.
- `distant_move_yards` takes the lock per observer: **fixed**, 717765c7. The new `ClientTable::insert_all` takes the lock once per heartbeat. The scratch `Clients` reuse was not done, because `broadcast` takes an `Arc`.

Checks: `cargo clippy --all-targets` is clean. `cargo nextest run --lib` passes (3407 tests). `cargo extended` passed 4172 of 4173; the one failure was `tests_kill_visual::a_smite_that_kills_a_young_wolf...`, a Smite hit list under load, which passed 3 of 3 when run alone. The client check passes.
